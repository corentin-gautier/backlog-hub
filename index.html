What it does

Where everything stands, at a glance.

Backlog.md keeps tasks as Markdown files in each repo. Backlog Hub reads them all and lays them out on one page, so you start the day knowing where everything stands.

Every board, one home

A card per project with its progress, grouped in categories you name and order by drag and drop. Boards are found in your folders on first run.

Coming up

Open tasks with a due date, across every project, soonest first. Tasks labelled monthly, quarterly or yearly come back once done.

A tab per project

Open a board in its own tab, reorder tabs, close them. Each board starts on its own port the first time you open it.

Claude Code beside you

A chat with Claude Code in each project, and a general one on the home page. Conversations keep running while the page is closed.

Encrypted docs

Keep a sensitive doc encrypted on disk and unlock it with Touch ID, right from the doc page (macOS, with the optional Backlog.md fork).

A desktop app

For macOS and Windows, light and dark, following your system. Opens at login and keeps running when its window is closed.

Claude Code, built in

Ask about the board you are looking at.

Press Ctrl+` on any board and Claude Code opens beside it, in that project's folder.

  • It sees what you see. Tasks, docs and code of the open project.
  • Pick up where you left off. Each project keeps its conversation; earlier ones are a click away.
  • Files and links open where they belong. Code in VS Code at the right line, pages in your browser.

Download

One download, everything inside.

The app brings its own runtime and the Backlog.md command line. Install it, and your boards are there.

macOS.dmg · Apple silicon or Intel Windows.exe installer · 64-bit

Install

On a Mac, drag Backlog Hub to Applications. On Windows, run the installer (SmartScreen may ask: More info › Run anyway).

Open your projects

Boards in your Projects and Documents folders show up on their own; add any other folder with the + button.

Bring Claude in

For the Claude Code panel, install the claude command line and sign in once.

# Or from source, on a Mac
$ brew install backlog-md
$ git clone https://github.com/corentin-gautier/backlog-hub.git
$ cd backlog-hub && ./install.sh

From source: Node 20+, and the Xcode Command Line Tools (xcode-select --install) for encrypted docs.
